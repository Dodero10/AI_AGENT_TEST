# Agentic RAG System

This project implements multiple approaches to Retrieval-Augmented Generation (RAG) systems with agent-based architectures, including adaptive routing, hierarchical agents, and evaluation capabilities.

## Features

- **Multiple RAG Implementations**:
  - Adaptive RAG with intelligent query routing
  - Hierarchical agent-based RAG with specialized teams
  - Basic RAG with Athina evaluation
  - CRAG (Corrective RAG) with document grading
  - Adaptive RAG (to be continue...)

- **Vector Store Options**:
  - Chroma with persistent storage
  - FAISS for efficient similarity search
  - Support for multiple embedding models (OpenAI, HuggingFace)

- **Advanced Features**:
  - Document relevance grading
  - Web search integration
  - PDF document processing
  - Interactive querying
  - Performance evaluation with Athina
